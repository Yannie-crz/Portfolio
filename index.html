Capstone Case Study: BCD Siomai GIS

Enterprise Architecture & Methodology

1. Executive Summary & Problem Statement

Mobile street food vendors in Bacolod and Talisay traditionally face severe discrepancies between commissary inventory distribution and daily evening cash reconciliations. Without real-time geospatial insight, commissary managers cannot verify cart placements, detect stock shortages during peak lunch hours, or prevent spoilage of unsold siomai dumplings.

2. Technical Solution Architecture

The BCD Siomai platform integrates three layers:

  • Mobile Vendor Client: Lightweight HTML5/JS progressive interface with Geolocation WatchPosition reporting coordinates every 60 seconds.
  • Commissary Central Backend: PHP 8 OOP API managing inventory batch tables, calculating automatic wholesale package discounts, and verifying transaction checksums.
  • Relational DB Tier: 3NF normalized MySQL database with tables for tbl_carts, tbl_inventory_batches, tbl_daily_returns, and tbl_audit_logs.

3. Key Results & Impact

98.4% Stock Reconciliation Accuracy
< 2s GPS Coordinate Update Interval
100% Zero Data Loss on Nightly Audit
